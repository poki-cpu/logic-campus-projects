HOW TO PLAY

一盏灯，一段逻辑。

用有限的逻辑门，搭出符合任务的电路。全部 关可直接体验，也可以按顺序挑战：先修复灯塔与能源，再挑战双输出半加器，最后重启路由中枢。

  1. 点击元件按钮添加逻辑门，拖动元件调整位置。
  2. 先点元件右侧输出圆点，再点下游左侧输入圆点；同一信号可以连向多个元件。
  3. 点 A、B 等开关切换 0 / 1，观察灯的状态。
  4. 运行检测会验证所有输入组合；失败时会展示具体反例。

器件采用美式门符号；空心小圆表示反相，不是连接端口。点击端口连接，导线交叉不代表相连。信号：灰色 0 为低电平，绿色 1 为高电平，虚线 ? 为未知。

三颗星如何获得

完成全部测试 +1 星；达到目标元件数 +1 星；本次挑战未使用提示 +1 星。提示按规律、思路、接法逐级展开；首次查看即失去本次无提示星，收起或撤销不能恢复。重置会清空电路、撤销/重做和提示记录，开始新挑战，不会清除最高星级。

键盘：Tab 切换端口，Enter / 空格连接；Esc 取消连线；选中元件后可用方向键移动、Delete 删除。未接端口显示 ?，不能通过检测。
