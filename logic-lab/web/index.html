FIELD NOTES

你的第一场逻辑实验

  1. 从半加器开始。 点击 A、B 开关，观察和 S 与进位 C。
  2. 加入一个逻辑门。 点击元件库，拖动到合适位置；选中后也可用方向键移动。
  3. 连接两个端口。 先点上游右侧圆点，再点下游左侧圆点。再次连接会替换原线，点击导线可删除。
  4. 目标与找错。 选择实验目标并检测全部组合；点击「复现首个失败」观察反例。高亮的是错误输出的上游候选路径，不代表已确定某个门有错。「找错练习」加载有意错误的半加器，可撤销恢复。
  5. 圈组与理解。 点击真值表复现输入；点击公式项看覆盖格、保留与消去的变量。卡诺图按格雷码排列，首尾边界也相邻。
  6. 留下实验。 本机自动保存，导出 JSON 可备份、再次导入；CSV 可用于实验报告。

器件采用美式门符号；空心小圆表示反相，不是连接端口。点击端口连接，导线交叉不代表相连。信号：灰色 0 为低电平，绿色 1 为高电平，虚线 ? 为未知。

本版使用确定性规则计算，不调用 AI 编造结果。仅支持一位、无反馈的组合逻辑；未连接端口记为「?」，不默认为 0。支持本站 JSON 格式，暂不支持 .circ 文件、时钟、触发器与子电路。

键盘：Tab 选择端口，Enter / 空格连接；Esc 取消；Delete 删除元件。载入实验会替换当前电路，可以撤销恢复。
